# Pages vedettes pour la boutique Shopify (référencement)

L'application app.zayado.net reste en noindex : c'est la boutique zayado.net qui porte le référencement. Voici 7 pages prêtes, à créer dans Shopify.

## Créer une page (à répéter pour chaque fichier)

1. Shopify › Boutique en ligne › Pages › Ajouter une page.
2. Titre : le « H1 » du tableau ci-dessous.
3. Dans l'éditeur, clique sur le bouton « Afficher le HTML » (icône <>), puis colle tout le contenu du fichier .html.
4. En bas : « Aperçu du référencement » › Modifier : colle le titre SEO et la méta-description, et mets l'adresse (handle) indiquée.
5. Enregistrer, puis ajoute la page au menu (Boutique en ligne › Navigation).

Les images viennent directement de l'appli (app.zayado.net/screenshots/…), elles s'afficheront dès la v14 déployée. Pour le meilleur référencement, tu peux les télécharger puis les importer dans Shopify › Contenu › Fichiers et remplacer les liens.

Les liens « Voir les tarifs » pointent vers /pages/tarifs : crée cette page avec la grille intégrée (code iframe dans RAILWAY.md, section « Grille tarifaire »).

## Données structurées FAQ (facultatif, pour les résultats enrichis Google)

Chaque page a un fichier .jsonld. Shopify retire les balises script collées dans l'éditeur : pour les ajouter, il faut un modèle de page dans le thème (Boutique en ligne › Thèmes › Modifier le code). Si tu veux, je te prépare ce modèle.
