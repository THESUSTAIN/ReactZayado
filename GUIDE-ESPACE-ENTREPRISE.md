# Guide — l'espace « Mon entreprise » de Vision-Act

Vision-Act n'invente pas une nouvelle base de données : **tes données restent dans TON fichier** (Google Sheets,
Excel sur OneDrive / SharePoint, ou Microsoft Lists). Vision-Act les lit, les écrit et les affiche en pages claires.

## En arrivant (dirigeant)
1. **Créer l'espace** : Mon entreprise › donne le nom de ton entreprise › « Activer ».
2. **Démarrage (3 étapes)** s'ouvre tout seul. Tant que la base n'est pas reliée, le menu ne montre que :
   Démarrage, Équipe, Bases & pages, Assistant, Réglages (pas de sections vides).

### Étape 1 — Relier ta base
| Où sont tes données ? | Ce que tu colles |
|---|---|
| Google Sheets | `https://docs.google.com/spreadsheets/d/…` (Partager › tous les utilisateurs disposant du lien › Éditeur) |
| Excel (OneDrive / SharePoint) | Cherche le classeur par son nom, ou colle son lien de partage (modification autorisée) |
| Microsoft Lists | `https://entreprise.sharepoint.com/sites/site/Lists/liste/AllItems.aspx` (une adresse par liste) |

Règles du fichier : **un onglet (ou une liste) par sujet**, **première ligne = titres des colonnes**, une ligne = un élément.
Pas de fichier ? « Je n'ai pas de classeur : utiliser l'espace sans base reliée » (les données restent alors dans Vision-Act).

### Étape 2 — Ajouter tes pages
Bases & pages › Pages prêtes à l'emploi (Planning, Absences, Temps, Pièces…) › « Ajouter » : chaque page crée son
onglet dans ton classeur et apparaît dans le menu. « Créer ma propre page » transforme n'importe quel onglet en
tableau, calendrier, frise, kanban ou chronomètre.

### Étape 3 — Inviter ton équipe
Équipe › inviter par e-mail ou par lien. Chacun ne voit que ce que tu lui ouvres (droits par personne).

## Ensuite
Le menu complet apparaît : Aujourd'hui, tes pages, Équipe, Décompte, Assistant, Bases & pages, Réglages.
Une modification faite dans Vision-Act est écrite dans ton fichier ; une modification dans le fichier est relue.
